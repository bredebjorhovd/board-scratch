# board-scratch

Throwaway repo for exercising herdr-board dispatch against runtimes other than
Claude Code. Nothing in here is real and nothing depends on it: a stray branch,
comment or commit costs nothing.

## notes.md

Each dispatched agent appends one line. That is the whole task — small enough to
finish in a turn, large enough to produce a commit, which is what the board
needs to see to settle the attempt.
